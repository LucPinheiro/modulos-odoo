# Modulos Personalizados Odoo 19

** TMS  **
Este módulo **TMS (Transport Management System)** está diseñado para gestionar de forma integral los servicios de **transporte y logística** en Odoo. Permite registrar **rutas comerciales**, controlar las solicitudes de los clientes y planificar detalladamente cada viaje con su vehículo y conductor. Además, automatiza la **facturación de los servicios** e incluye herramientas específicas para supervisar el **kilometraje y el mantenimiento de neumáticos**.
