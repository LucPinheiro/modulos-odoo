# Módulos Personalizados Odoo 18

## 📦 pos_restaurant_api (API de Punto de Venta para Restaurantes)

Este módulo está diseñado para conectar de forma externa aplicaciones móviles y plataformas de delivery con Odoo.

Permite realizar las siguientes acciones:

* **Integración Omnicanal:** Recepción de pedidos en tiempo real provenientes de React Native, Glovo y Just Eat.
* **Conexión POS Nativa:** Inyección directa de órdenes en los modelos `pos.order` y `pos.session` activos.
* **Flujo Automatizado:** Sincronización inmediata con el stock de inventario tras cada venta procesada.
* **Gestión de Cocina:** Envío automático de comandas a las pantallas de preparación y ticketeras del restaurante.
