# Módulos Personalizados Odoo 18

* **pos_restaurant_api**: Addon personalizado que expone controladores web JSON-RPC 2.0 seguros para la gestión externa de comandas.
* **Integración Omnicanal**: Permite recibir pedidos en tiempo real provenientes de la App móvil (React Native) y plataformas de delivery (Glovo, Just Eat).
* **Conexión POS Nativa**: Inyecta las órdenes directamente en los modelos `pos.order` y `pos.session` activos de Odoo 18.
* **Flujo Automatizado**: Automatiza la actualización de stock en inventario y activa el envío inmediato a las pantallas de preparación en cocina.
